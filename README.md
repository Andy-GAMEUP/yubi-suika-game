# 🍉 유비의 수박게임

같은 과일 두 개를 부딪혀 더 큰 과일로 키우는 물리 퍼즐 게임입니다. 체리에서 시작해 수박까지 키워 보세요!

HTML 파일 하나로 되어 있어 설치나 빌드가 필요 없습니다.

## 실행

**바로 플레이:** https://andy-gameup.github.io/yubi-suika-game/

로컬에서 실행:

```bash
open my-suika/index.html
```

물리 엔진(Matter.js)과 글꼴(Gaegu)을 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 이동 / 터치 드래그 | 떨어뜨릴 위치 이동 |
| 클릭 / 터치 떼기 | 과일 떨어뜨리기 |
| ← → | 위치 이동 |
| Space / Enter / ↓ | 떨어뜨리기, 게임오버 후 다시 시작 |

## 특징

- **크레파스 그림체**: 과일 11종과 구름 캐릭터 '몽실이'를 캔버스로 직접 그림 (이미지 파일 없음)
- **3D 과일 나무상자**: 원근감 있는 판자 상자, 윗테두리가 데드라인
- **말랑한 물리**: 작은 과일일수록 잘 튀고, 부딪힌 방향으로 찌그러졌다 출렁이며 복원
- **합체 연출**: 새 과일이 커지며 주변을 밀어내고, 흰 섬광과 과즙 입자가 퍼짐
- **진화의 고리**: 11단계 진화를 원형으로 표시, 도달한 단계 강조
- **랭킹보드**: TOP 10 점수와 달성 날짜·시간을 브라우저에 저장
- **사운드**: 과일마다 다른 합성 효과음, 콤보 음계, 마림바 풍 배경음악 (Web Audio로 생성)
- **게임오버 유예**: 데드라인 위에 2초 이상 머물러야 게임오버

## 점수

합쳐지는 과일 단계에 따라 1, 3, 6, 10, 15, 21, 28, 36, 45, 55, 66점. 0.9초 안에 연달아 합치면 콤보 보너스가 붙습니다.

## 폴더 구성

- `my-suika/index.html` — 게임 전체
- `suika-analysis/BENCHMARK.md` — 참고한 웹 수박게임의 구조·규칙 분석 메모

분석에 사용한 원작 리소스와 코드는 저작물이므로 저장소에 포함하지 않았습니다. 이 게임의 그래픽과 사운드는 모두 직접 제작했습니다.
