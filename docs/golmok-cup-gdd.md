## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 탑뷰(3/4 시점) **2D 픽셀아트 아케이드 축구** |
| 경기 | **11대11 정식 축구**, 전·후반, 실제 규칙(파울·카드·오프사이드·세트피스) |
| 한 줄 소개 | 짧고 빠른 경기, 단순한 조작에 깊이를 더한 차지 킥, 그리고 축구장에서 벌어지는 엉뚱한 사건들 |

| 개발 | 1–3명 + Claude, 약 9–10개월 ([개발 계획](golmok-cup-dev-plan.md)) |

### 1.1 원작과의 관계: "같은 방식, 다른 표현"
| 원작에서 **가져오는 것** (장르 메커니즘) | 원작과 **다르게 만드는 것** (표현·데이터) |
|---|---|
| 11대11, 탑뷰, 짧은 실시간 경기 | 세계관: 가상의 도시 리그와 국가 대항전 |
| 차지 시간으로 킥 세기·종류를 정하는 입력 | 캐릭터·경기장·UI·아이콘 아트 전부 새로 제작 |
| 능력치 8종 + 스킬 해금 구조 | 능력치·스킬 이름, 구성, 수치를 자체 설계 |
| 결정 트리 기반 팀 AI, 포메이션 | 팀·선수 이름 전부 가상 (실존 국가는 이름만, 국기·실존 선수 없음) |
| 공중·바운드 중심 공 물리 | 수치는 원작을 기준점으로만 쓰고 직접 튜닝 |
| 대회(조별·녹아웃·리그) | 차별화 모드: **카오스 컵**(룰 카드), **동네 클럽 커리어** |

**금지 사항**: 원작 APK에서 추출한 에셋·텍스트·데이터 파일(`docs/reference/`)을 게임에 넣지 않습니다. 원작의 수치표(파울 확률표, 선수 유형표 등)를 그대로 옮기지 않습니다.

## 2. 핵심 경험 (디자인 기둥)

1. **3분 안에 끝나는 진짜 축구**: 실제 축구 규칙을 다 갖추되 경기 시간은 짧게(기본 3분, 2–10분 선택).
2. **한 버튼에 담긴 깊이**: 누르는 시간 하나로 패스·슛의 종류, 세기, 정확도, 실축 위험이 정해집니다.
3. **통통 튀는 공**: 공중에서는 감속이 거의 없고 바운드할 때마다 느려지는 물리. 공 궤적을 읽는 재미.
4. **웃음이 나는 돌발 사건**: 비·눈·바람, 경기장 장애물, 관중 난입, 맞으면 기절하는 공.

## 3. 조작

### 3.1 모바일 (가상 패드)
| 입력 | 공 있을 때 | 공 없을 때 (수비) |
|---|---|---|
| 왼쪽 가상 스틱 | 이동·드리블 | 이동 |
| A (짧게 / 길게) | 짧은 패스 / 스루패스·로빙 (차지) | 선수 전환 |
| B (차지) | 슛: 칩 → 낮게 → 중간 → 강하게 → 파워 | 슬라이딩 태클 |
| C | 스프린트 / 기술(드리블 회피 등) | 압박 / 블록 태클 |
| 별(★) | 슈퍼슛 (게이지 충전 시) | 슈퍼 세이브 (GK) |

- 스틱을 기울인 방향으로 차고, 슛 차지 중에 스틱을 돌리면 감아차기가 됩니다.
- 보조 옵션: 자동 슛 조준(골문 쪽 일정 각도 안이면 보정), 자동 선수 전환, 자동 패스 대상 선택.

### 3.2 패드·키보드
같은 동작을 패드 버튼에 배정합니다. Steam 버전에서는 같은 기기 2–4인 플레이를 지원합니다.

### 3.3 차지 입력 규칙 (자체 설계)
| 누른 시간 | 슛 | 패스 |
|---|---|---|
| ~0.15초 | 칩슛 | 빠른 크로스 |
| ~0.30초 | 낮은 슛 | 짧은 패스 |
| ~0.50초 | 중간 슛 | 스루패스 |
| ~0.70초 | 강한 슛 | — |
| ~0.90초 | 파워 슛 | 로빙·롱패스 |
| 1.0초 초과 | 실축 위험 구간 (오차 급증) | — |

차지 게이지는 선수 발밑에 표시합니다. 정확한 구간 값은 프로토타입에서 튜닝합니다.

## 5. 선수와 팀

### 5.1 능력치 (8종, 0–100)
| 능력치 | 영향 |
|---|---|
| 속도 | 최고 이동 속도 |
| 가속 | 최고 속도까지 걸리는 시간 |
| 민첩 | 방향 전환 속도, GK 반응 |
| 킥 파워 | 슛·패스 세기 |
| 정확도 | 슛·패스 오차 |
| 볼 키핑 | 공 받기 허용 속도, 드리블 |
| 수비 | 태클 성공률, 마킹 |
| 체력 | 스프린트 지속, 후반 성능 저하 |

- 실제 값 = `Lerp(최소, 최대, 능력치)` × 상태 배율(체력, 부상, 사기). 최소–최대 폭은 **원작보다 넓게** 잡아(예: 속도 차이 10% → 20%) 선수 차이를 체감할 수 있게 합니다.
- 포지션: GK, DF, MF, FW. 포지션이 맞지 않으면 능력치 감소.

### 5.2 스킬 (자체 구성 약 30종)
- 원작처럼 **스킬이 기술을 해금**하는 구조입니다. 예: 오버헤드킥 스킬이 없으면 시도할 수 없음.
- 분류: 공 다루기 / 패스 / 슛 / 공중볼 / 수비 / 세트피스 / 팀 전술(AI 강화) / GK.
- 선수당 3–8개 보유. 커리어 모드에서 경험치로 습득합니다.

### 5.3 팀
- 출시 시 **48팀**(가상 국가대표 32 + 도시 클럽 16). 팀마다 18명, 포메이션, 전술 성향(패스·슛·태클·돌파 0–100).
- 팀 등급 5단계. 등급 간 평균 능력치 차이를 원작보다 크게 설계합니다.
- 유니폼은 팔레트 교체(색 2–3개 + 무늬)로 무한 조합.

## 6. 시스템 상세

### 6.1 공 물리 (2.5D, 자체 구현)
원작 분석([수치 분석 7장](pixel-cup-soccer-tuning.md))에서 확인한 구조를 따르고, 수치는 새로 정합니다.

| 요소 | 설계 | 초기값 (튜닝 대상) |
|---|---|---|
| 좌표 | x, y (경기장 평면) + z (높이), 고정 60틱 | 경기장 약 2400 × 1400 단위 |
| 적분 | 반암시적 Euler | — |
| 중력 | 공은 약하게, 선수는 강하게 | 공 −320, 선수 −800 |
| 공중 | 수평 감속 없음 | 마찰 1.0 |
| 바운드 | 수직 속도 반전 × Z손실, 수평 속도 × XY손실(바운드 세기에 따라 보간) | Z 0.65, XY 0.65(약)–0.40(강) |
| 지면 구름 | `vel *= pow(마찰, dt)` | 초당 0.75 (원작 0.965보다 강하게) |
| 바닥 종류 | 잔디·인조잔디·모래·흙·눈 등 데이터로 정의 | 5종 |
| 감아차기 | 공 속도 벡터를 초당 일정 각도로 회전 | 최대 60°/s |

**원작과 다르게 하는 점**: 장애물 효과(물웅덩이 등)를 프레임당 곱셈이 아니라 dt 기반으로 바꿔 프레임레이트에 영향을 받지 않게 합니다.

### 6.2 AI
- **팀 AI**: 포메이션 슬롯 + 공 위치에 따른 대형 이동(공격·수비 라인), 전술 4종(일반, 압박, 역습, 수비).
- **선수 AI**: 결정 트리. 각 노드는 "행동 가능 여부 확인 + 확률 주사위" 구조이고, 노드 확률은 팀 성향에서 옵니다.
  - 공 소유 시: 슛 / 패스(짧게·스루·로빙) / 드리블 / 스프린트
  - 비소유 시: 공 쫓기 / 마크 / 빈 공간 침투 / 대형 복귀 / 태클 종류 선택
  - GK: 위치 잡기, 다이빙, 뛰쳐나가기, 펀칭, 빌드업
- **경기 흐름**: 지고 있으면 후반 일정 시점부터 공격적으로 전환합니다.
- **난이도**: 상대 능력치 배율 + AI 판단 정확도. 원작처럼 내 팀을 크게 올리는 방식(쉬움 ×1.8)은 쓰지 않고, AI 실수율로 조절합니다.

### 6.3 반칙 판정 (자체 수치)
- 입력: 태클 종류(슬라이딩·블록·정면), 방향(뒤·옆·앞), 상대가 공을 가졌는지, 거리.
- 출력: 파울 → 카드(옐로·레드) → 부상 순서로 확률 판정. 옵션의 "파울 엄격도" 5단계로 배율 조정.
- 확률표는 자체 설계하고 플레이테스트로 맞춥니다. 목표는 경기당 파울 2–4회, 카드 0–1장입니다.

### 6.4 돌발 요소
| 분류 | 예시 | 출시 |
|---|---|---|
| 날씨 | 비(공 미끄러짐), 눈(빨리 멈춤), 바람(공중 공 밀림), 밤 경기 | 출시 |
| 경기장 장애물 | 물웅덩이, 진흙, 스프링클러, 떨어진 쓰레기 | 출시 |
| 사건 | 관중 난입, 떠돌이 개, 조명탄 연기, 공에 맞아 기절 | 출시 3종 → 업데이트 |
| 카오스 컵 룰 카드 | 경기 전 양 팀이 카드 1장씩 내서 그 경기 규칙을 바꿈 | 출시 후 업데이트 |

### 6.5 카메라·연출
- 공과 공을 가진 선수를 부드럽게 따라가는 카메라, 줌 3단계.
- 골 컷인, 슬로모션(옵션), 즉석 리플레이(결정론 시뮬레이션 재생), 화면 흔들림.
- HUD: 점수·시간, 미니맵, 선택 선수 표시, 차지 게이지, 스태미나 바.

## 8. 아트·사운드

### 8.1 원칙: 2D 픽셀아트 아케이드 축구 스타일 유지
- 게임 전체를 **2D 픽셀아트**로 만듭니다. 3D 모델, 벡터 일러스트, 고해상도 페인팅은 쓰지 않습니다(UI 포함).
- 장르 감성은 원작과 같은 **레트로 아케이드 축구**를 유지합니다: 작은 도트 선수, 과장된 동작, 화면 가득 움직이는 22명, 빠른 템포.
- 같은 스타일 **안에서** 독자적인 그림체를 만듭니다. 캐릭터 비율, 팔레트, 외곽선, 소품은 원작과 다르게 그리고, 원작 스프라이트를 따라 그리지 않습니다.

### 8.2 기술 기준
| 항목 | 기준 |
|---|---|
| 내부 해상도 | 640×360, 정수 배율 확대(Godot `viewport` 스트레치 + 정수 스케일), 안티앨리어싱 없음 |
| 텍스처 | 필터 없음(Nearest), 모든 스프라이트는 픽셀 그리드에 정렬 |
| 캐릭터 | 2.5등신, 약 16×24px, 8방향(좌우 반전으로 5방향 제작) |
| 애니메이션 | 달리기 6, 킥 4, 태클 4, 헤더 4, 다이빙 5, 세리머니 등. 선수당 약 40개 동작 |
| 다양화 | 팔레트 교체 셰이더: 피부·머리·눈·유니폼(상·하·양말·무늬) |
| 시점 | 3/4 오블리크. 경기장 라인은 기울어진 투시로 그림 |
| 공 | 8×8px, 회전 애니메이션 4프레임 + 그림자(높이에 따라 간격) |
| 폰트 | 픽셀 폰트(한글 포함, 11px·16px 두 크기) |
| 연출 | 픽셀 파티클(잔디, 먼지, 비, 눈), 골 컷인, 화면 흔들림, 선택형 CRT 필터 |

### 8.3 그림체 차별화
- 원작보다 **밝고 채도 높은 팔레트**(32–48색 제한 팔레트), 굵은 1px 검은 외곽선
- 캐릭터 얼굴을 약간 크게 그려 표정(기절, 분노, 환호)을 강조
- 경기장 배경에 동네·생활감 있는 소품(시장 천막, 옥상 빨래, 자판기, 응원 현수막)
