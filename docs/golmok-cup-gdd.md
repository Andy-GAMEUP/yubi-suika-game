### 1.1 원작과의 관계: "같은 방식, 다른 표현"
| 원작에서 **가져오는 것** (장르 메커니즘) | 원작과 **다르게 만드는 것** (표현·데이터) |
|---|---|
| 11대11, 탑뷰, 짧은 실시간 경기 | 세계관: 가상의 도시 리그와 국가 대항전 |
| 차지 시간으로 킥 세기·종류를 정하는 입력 | 캐릭터·경기장·UI·아이콘 아트 전부 새로 제작 |
| 능력치 8종 + 스킬 해금 구조 | 능력치·스킬 이름, 구성, 수치를 자체 설계 |
| 결정 트리 기반 팀 AI, 포메이션 | 팀·선수 이름 전부 가상 (실존 국가는 이름만, 국기·실존 선수 없음) |
| 공중·바운드 중심 공 물리 | 수치는 원작을 기준점으로만 쓰고 직접 튜닝 |
| 대회(조별·녹아웃·리그) | 차별화 모드: **카오스 컵**(룰 카드), **동네 클럽 커리어** |
| 단일 구매 오프라인 게임 | **선수 카드 수집 RPG + 유저 간 마켓 + 온라인 티어전** (원작에 없는 구조) |

**금지 사항**: 원작 APK에서 추출한 에셋·텍스트·데이터 파일(`docs/reference/`)을 게임에 넣지 않습니다. 원작의 수치표(파울 확률표, 선수 유형표 등)를 그대로 옮기지 않습니다.

## 2. 핵심 경험 (디자인 기둥)

1. **3분 안에 끝나는 진짜 축구**: 실제 축구 규칙을 다 갖추되 경기 시간은 짧게(기본 3분, 2–10분 선택).
2. **한 버튼에 담긴 깊이**: 누르는 시간 하나로 패스·슛의 종류, 세기, 정확도, 실축 위험이 정해집니다.
3. **통통 튀는 공**: 공중에서는 감속이 거의 없고 바운드할 때마다 느려지는 물리. 공 궤적을 읽는 재미.
4. **웃음이 나는 돌발 사건**: 비·눈·바람, 경기장 장애물, 관중 난입, 맞으면 기절하는 공.
5. **나만의 클럽을 키우는 수집**: 선수를 뽑고, 키우고, 사고팔아 내 팀을 만들고, 그 팀으로 다른 유저와 겨룹니다.

## 3. 조작

### 3.1 모바일 (가상 패드)
| 입력 | 공 있을 때 | 공 없을 때 (수비) |
|---|---|---|
| 왼쪽 가상 스틱 | 이동·드리블 | 이동 |
| A (짧게 / 길게) | 짧은 패스 / 스루패스·로빙 (차지) | 선수 전환 |
| B (차지) | 슛: 칩 → 낮게 → 중간 → 강하게 → 파워 | 슬라이딩 태클 |
| C | 스프린트 / 기술(드리블 회피 등) | 압박 / 블록 태클 |
| 별(★) | 슈퍼슛 (게이지 충전 시) | 슈퍼 세이브 (GK) |

- 스틱을 기울인 방향으로 차고, 슛 차지 중에 스틱을 돌리면 감아차기가 됩니다.
- 보조 옵션: 자동 슛 조준(골문 쪽 일정 각도 안이면 보정), 자동 선수 전환, 자동 패스 대상 선택.

### 3.2 패드·키보드
같은 동작을 패드 버튼에 배정합니다. Steam 버전에서는 같은 기기 2–4인 플레이를 지원합니다.

### 3.3 차지 입력 규칙 (자체 설계)
| 누른 시간 | 슛 | 패스 |
|---|---|---|
| ~0.15초 | 칩슛 | 빠른 크로스 |
| ~0.30초 | 낮은 슛 | 짧은 패스 |
| ~0.50초 | 중간 슛 | 스루패스 |
| ~0.70초 | 강한 슛 | — |
| ~0.90초 | 파워 슛 | 로빙·롱패스 |
| 1.0초 초과 | 실축 위험 구간 (오차 급증) | — |

차지 게이지는 선수 발밑에 표시합니다. 정확한 구간 값은 프로토타입에서 튜닝합니다.

## 5. 선수와 팀

### 5.1 능력치 (8종, 0–100)
| 능력치 | 영향 |
|---|---|
| 속도 | 최고 이동 속도 |
| 가속 | 최고 속도까지 걸리는 시간 |
| 민첩 | 방향 전환 속도, GK 반응 |
| 킥 파워 | 슛·패스 세기 |
| 정확도 | 슛·패스 오차 |
| 볼 키핑 | 공 받기 허용 속도, 드리블 |
| 수비 | 태클 성공률, 마킹 |
| 체력 | 스프린트 지속, 후반 성능 저하 |

- 실제 값 = `Lerp(최소, 최대, 능력치)` × 상태 배율(체력, 부상, 사기). 최소–최대 폭은 **원작보다 넓게** 잡아(예: 속도 차이 10% → 20%) 선수 차이를 체감할 수 있게 합니다.
- 포지션: GK, DF, MF, FW. 포지션이 맞지 않으면 능력치 감소.

### 5.2 특성 (자체 구성 약 30종)
- 원작처럼 **특성이 기술을 해금**하는 구조입니다. 예: "오버헤드킥" 특성이 없으면 시도할 수 없음.
- 분류: 공 다루기 / 패스 / 슛 / 공중볼 / 수비 / 세트피스 / 팀 전술(AI 강화) / GK.
- 선수 카드마다 특성 슬롯이 있고, 강화로 슬롯을 열고 특성 레벨을 올립니다(5.4절).

### 5.3 선수 카드 (영웅 카드 수집 RPG)
모든 선수는 **카드**로 존재합니다. 유저의 클럽은 보유 카드 중 18명(선발 11 + 교체 7)으로 구성합니다.

| 등급 | 능력치 범위 (0–100) | 특성 슬롯 | 최대 강화 | 비고 |
|---|---|---|---|---|
| 일반 (★1) | 40–60 | 1 | +5 | |
| 레어 (★2) | 55–70 | 2 | +7 | |
| 에픽 (★3) | 65–80 | 3 | +10 | |
| 레전드 (★4) | 75–90 | 4 | +10 | 고유 특성 1개 고정 |
| 아이콘 (★5) | 85–95 | 5 | +10 | 고유 특성 + 전용 세리머니. 시즌 한정 |

- 카드 구성: 선수 외형(팔레트 조합) + 포지션 + 능력치 8종 + 특성 + 등급 + 강화 단계 + 레벨
- 같은 선수라도 등급이 다른 카드가 있을 수 있습니다(예: 레어 "김골목", 레전드 "김골목").
- 모든 선수는 **가상 인물**입니다. 실존 선수의 이름·외모는 쓰지 않습니다.

### 5.4 성장·강화
| 단계 | 방법 | 효과 |
|---|---|---|
| 레벨 업 (1–50) | 경기 출전 경험치 + 훈련 카드(재료) + 코인 | 능력치 소폭 상승 (레벨당 +0.3, 등급 상한 내) |
| 강화 (+1 ~ +10) | **같은 선수 카드(중복)** 또는 강화석 + 코인 | 능력치 +1/단계, +3·+6·+9에서 특성 슬롯 해금·특성 레벨 업 |
| 특성 훈련 | 특성서(재료) | 특성 레벨 1–3 (효과 강화) |
| 승급 | 같은 등급 카드 3장 합성 → 상위 등급 랜덤 1장 | 저등급 카드 소모처 |
| 방출 | 카드를 분해 | 강화석·코인 환급 |

- **강화 실패 없음**: 강화는 재료만 있으면 항상 성공합니다. 뽑기 위에 또 다른 확률 장치를 겹치지 않기 위해서입니다.
- 클럽 전력(OVR) = 선발 11명 능력치를 포지션 비중으로 가중 평균한 값. 매칭에 사용합니다(9.5절).

### 5.5 클럽과 AI 팀
- **내 클럽**: 이름·엠블럼·유니폼을 정하고, 보유 카드로 18명을 구성합니다. 포메이션과 전술 성향(패스·슛·태클·돌파 0–100)을 설정합니다.
- 시작 시 일반·레어 카드로 구성된 기본 스쿼드 18명과 고급 덱 10+1회 무료 1번을 지급합니다.
- **AI 팀** (시즌 리그용): 출시 시 48팀(가상 국가대표 32 + 도시 클럽 16), 팀 등급 5단계. 등급 간 능력치 차이를 원작보다 크게 설계합니다.
- 유니폼은 팔레트 교체(색 2–3개 + 무늬)로 무한 조합합니다.

## 6. 시스템 상세

### 6.1 공 물리 (2.5D, 자체 구현)
원작 분석([수치 분석 7장](pixel-cup-soccer-tuning.md))에서 확인한 구조를 따르고, 수치는 새로 정합니다.

| 요소 | 설계 | 초기값 (튜닝 대상) |
|---|---|---|
| 좌표 | x, y (경기장 평면) + z (높이), 고정 60틱, **고정소수점 연산**(온라인 대전 결정론용) | 경기장 약 2400 × 1400 단위 |
| 적분 | 반암시적 Euler | — |
| 중력 | 공은 약하게, 선수는 강하게 | 공 −320, 선수 −800 |
| 공중 | 수평 감속 없음 | 마찰 1.0 |
| 바운드 | 수직 속도 반전 × Z손실, 수평 속도 × XY손실(바운드 세기에 따라 보간) | Z 0.65, XY 0.65(약)–0.40(강) |
| 지면 구름 | `vel *= pow(마찰, dt)` | 초당 0.75 (원작 0.965보다 강하게) |
| 바닥 종류 | 잔디·인조잔디·모래·흙·눈 등 데이터로 정의 | 5종 |
| 감아차기 | 공 속도 벡터를 초당 일정 각도로 회전 | 최대 60°/s |

**원작과 다르게 하는 점**: 장애물 효과(물웅덩이 등)를 프레임당 곱셈이 아니라 dt 기반으로 바꿔 프레임레이트에 영향을 받지 않게 합니다.

### 6.2 AI
- **팀 AI**: 포메이션 슬롯 + 공 위치에 따른 대형 이동(공격·수비 라인), 전술 4종(일반, 압박, 역습, 수비).
- **선수 AI**: 결정 트리. 각 노드는 "행동 가능 여부 확인 + 확률 주사위" 구조이고, 노드 확률은 팀 성향에서 옵니다.
  - 공 소유 시: 슛 / 패스(짧게·스루·로빙) / 드리블 / 스프린트
  - 비소유 시: 공 쫓기 / 마크 / 빈 공간 침투 / 대형 복귀 / 태클 종류 선택
  - GK: 위치 잡기, 다이빙, 뛰쳐나가기, 펀칭, 빌드업
- **경기 흐름**: 지고 있으면 후반 일정 시점부터 공격적으로 전환합니다.
- **난이도**: 상대 능력치 배율 + AI 판단 정확도. 원작처럼 내 팀을 크게 올리는 방식(쉬움 ×1.8)은 쓰지 않고, AI 실수율로 조절합니다.

### 6.3 반칙 판정 (자체 수치)
- 입력: 태클 종류(슬라이딩·블록·정면), 방향(뒤·옆·앞), 상대가 공을 가졌는지, 거리.
- 출력: 파울 → 카드(옐로·레드) → 부상 순서로 확률 판정. 옵션의 "파울 엄격도" 5단계로 배율 조정.
- 확률표는 자체 설계하고 플레이테스트로 맞춥니다. 목표는 경기당 파울 2–4회, 카드 0–1장입니다.

### 6.4 돌발 요소
| 분류 | 예시 | 출시 |
|---|---|---|
| 날씨 | 비(공 미끄러짐), 눈(빨리 멈춤), 바람(공중 공 밀림), 밤 경기 | 출시 |
| 경기장 장애물 | 물웅덩이, 진흙, 스프링클러, 떨어진 쓰레기 | 출시 |
| 사건 | 관중 난입, 떠돌이 개, 조명탄 연기, 공에 맞아 기절 | 출시 3종 → 업데이트 |
| 카오스 컵 룰 카드 | 경기 전 양 팀이 카드 1장씩 내서 그 경기 규칙을 바꿈 | 출시 후 업데이트 |

### 6.5 카메라·연출
- 공과 공을 가진 선수를 부드럽게 따라가는 카메라, 줌 3단계.
- 골 컷인, 슬로모션(옵션), 즉석 리플레이(결정론 시뮬레이션 재생), 화면 흔들림.

## 8. 아트·사운드

### 8.1 원칙: 2D 픽셀아트 아케이드 축구 스타일 유지
- 게임 전체를 **2D 픽셀아트**로 만듭니다. 3D 모델, 벡터 일러스트, 고해상도 페인팅은 쓰지 않습니다(UI 포함).
- 장르 감성은 원작과 같은 **레트로 아케이드 축구**를 유지합니다: 작은 도트 선수, 과장된 동작, 화면 가득 움직이는 22명, 빠른 템포.
- 같은 스타일 **안에서** 독자적인 그림체를 만듭니다. 캐릭터 비율, 팔레트, 외곽선, 소품은 원작과 다르게 그리고, 원작 스프라이트를 따라 그리지 않습니다.

### 8.2 기술 기준
| 항목 | 기준 |
|---|---|
| 내부 해상도 | 640×360, 정수 배율 확대(Godot `viewport` 스트레치 + 정수 스케일), 안티앨리어싱 없음 |
| 텍스처 | 필터 없음(Nearest), 모든 스프라이트는 픽셀 그리드에 정렬 |
| 캐릭터 | 2.5등신, 약 16×24px, 8방향(좌우 반전으로 5방향 제작) |
| 애니메이션 | 달리기 6, 킥 4, 태클 4, 헤더 4, 다이빙 5, 세리머니 등. 선수당 약 40개 동작 |
| 다양화 | 팔레트 교체 셰이더: 피부·머리·눈·유니폼(상·하·양말·무늬) |
| 시점 | 3/4 오블리크. 경기장 라인은 기울어진 투시로 그림 |
| 공 | 8×8px, 회전 애니메이션 4프레임 + 그림자(높이에 따라 간격) |
| 폰트 | 픽셀 폰트(한글 포함, 11px·16px 두 크기) |
| 연출 | 픽셀 파티클(잔디, 먼지, 비, 눈), 골 컷인, 화면 흔들림, 선택형 CRT 필터 |

### 8.3 그림체 차별화
- 원작보다 **밝고 채도 높은 팔레트**(32–48색 제한 팔레트), 굵은 1px 검은 외곽선
- 캐릭터 얼굴을 약간 크게 그려 표정(기절, 분노, 환호)을 강조
- 경기장 배경에 동네·생활감 있는 소품(시장 천막, 옥상 빨래, 자판기, 응원 현수막)
- **경기장**: 출시 8곳(도시 경기장, 해변, 눈 덮인 산, 옥상, 시장 옆 운동장 등)

### 8.4 사운드
- 칩튠 BGM 6곡, 관중 함성 레이어(점수·위기 상황에 따라 변화), 효과음 약 120개. 외주 또는 에셋.

## 9. 비즈니스 모델 (무료 플레이)

### 9.1 재화
| 재화 | 획득 | 사용처 | 현금화 |
|---|---|---|---|
| **골드볼** (유료 재화) | 결제, 일부 무료 지급(출석·업적·토너먼트) | 고급 덱, 대전 티켓, 시즌 패스, 꾸미기 | 불가 |
| **클럽 코인** (일반 재화) | 경기 보상, 시즌 리그, 마켓 판매 대금 | 일반 덱, 레벨 업·강화 비용, **마켓 구매** | 불가 |
| 강화석·훈련 카드·특성서 | 경기 보상, 방출, 이벤트 | 강화·레벨 업·특성 훈련 | — |
| 대전 티켓 | 매일 무료 10장, 골드볼로 추가 구매 | 온라인 티어전 1경기 = 1장 | — |

- **마켓 거래는 클럽 코인으로만** 합니다. 골드볼(유료 재화)은 유저 간에 이동하지 않습니다. 현금 거래(RMT)와 사행성 문제를 막기 위한 핵심 원칙입니다.
- 골드볼 상품 예시: ₩1,200(100) · ₩5,900(520) · ₩12,000(1,100) · ₩33,000(3,200) · ₩59,000(6,000) · ₩99,000(10,500)

### 9.2 선수 덱 뽑기
| 구분 | 일반 덱 | 고급 덱 |
|---|---|---|
| 가격 | 클럽 코인 5,000 / 1회 (일일 무료 1회) | 골드볼 300 / 1회, **10+1회 3,000** |
| 일반 ★1 | 70% | — |
| 레어 ★2 | 25% | 62% |
| 에픽 ★3 | 4.6% | 30% |
| 레전드 ★4 | 0.4% | 7.5% |
| 아이콘 ★5 | — | 0.5% (시즌 한정 풀) |
| 확정 보상 | — | 10+1회에 **에픽 이상 1장 확정** |
| 천장 | — | 고급 덱 **80회 안에 레전드 이상 확정** (시즌 동안 누적, 다음 시즌으로 이월) |

- **확률 공개**: 게임 내 덱 화면과 공식 홈페이지에 등급별·선수별 확률을 공개합니다(게임산업법 확률형 아이템 표시 의무, 각 스토어 정책). 뽑기 결과 이력을 30일 동안 조회할 수 있게 합니다.
- **중복 카드**는 강화 재료가 됩니다(5.4절). 그래서 중복도 의미가 있습니다.
- **픽업 덱**(이벤트): 특정 레전드·아이콘 확률을 높인 고급 덱. 2주 단위로 교체합니다.
- 일일 결제 한도 설정 기능, 미성년자 월 결제 한도를 둡니다.

### 9.3 FA 에이전트 마켓 (유저 간 거래)
팔고 싶은 선수 카드를 "FA 에이전트"에게 맡겨 등록하면, 다른 유저가 클럽 코인으로 사 갑니다.

| 규칙 | 내용 | 목적 |
|---|---|---|
| 거래 재화 | 클럽 코인만 | 현금 거래·사행성 방지 |
| 수수료 (에이전트 수수료) | 판매가의 10% (재화 소멸) | 인플레이션 억제 |
| 가격 범위 | 해당 카드 최근 7일 거래 시세의 50–200% 안에서만 등록 | 부계정 간 재화 이동, 사기 방지 |
| 등록 기간 | 24·48·72시간, 미판매 시 자동 반환 | |
| 등록 한도 | 동시 10장, 하루 등록 20회 | 매크로 방지 |
| 거래 가능 카드 | 레어 이상. 강화 +7 이상, 귀속 카드(이벤트 보상 등)는 거래 불가 | 고강화 카드 RMT 방지 |
| 재판매 제한 | 구매한 카드는 7일 동안 재등록 불가 | 되팔기 투기 억제 |
| 계정 조건 | 클럽 레벨 10 이상, 휴대폰 인증 | 부계정 악용 방지 |
| 검색·정렬 | 선수명·등급·포지션·능력치·특성·가격, 시세 그래프 | |
| 서버 판정 | 등록·구매·정산은 모두 서버 트랜잭션, 거래 로그 보관 | 복제·롤백 방지 |

- 판매자는 수수료를 뺀 대금을 즉시 받습니다. 구매자는 카드를 즉시 받습니다.
- 운영 도구: 이상 거래(단시간 다량, 시세 이탈, 계정 간 반복 거래) 탐지와 제재.

### 9.4 온라인 티어전과 대전 티켓
- 1:1 실시간 대전. 각자 자기 클럽 11명을 조작합니다(선택 선수 1명 조작 + 나머지 AI).
- 경기 시간 3분(고정), 동점이면 바로 승부차기.
- **대전 티켓**
  - 매일 00:00(KST)에 **무료 10장** 지급. 무료 티켓은 이월되지 않습니다.
  - 추가 티켓은 골드볼로 구매: 1장 30 · 5장 130 · 10장 240. **하루 구매 한도 20장**
  - 매칭 취소·상대 이탈로 경기가 성립하지 않으면 티켓을 돌려줍니다.
  - 내가 중간에 나가면 패배 처리하고 티켓을 소모합니다.
- 친구 대전·AI 친선전·시즌 리그는 티켓을 쓰지 않습니다.

### 9.5 티어와 시즌
| 티어 | 단계 | 승리 / 패배 점수 |
|---|---|---|
| 브론즈 | III–I | +30 / −10 |
| 실버 | III–I | +25 / −15 |
| 골드 | III–I | +20 / −18 |
| 플래티넘 | III–I | +20 / −20 |
| 다이아몬드 | III–I | +18 / −20 |
| 마스터 | 단일 (점수제) | +15 / −18 |
| 챔피언 | 마스터 상위 100명 | 순위제 |

- 단계당 100점. 연승 보너스(3연승부터 +5).
- **시즌 = 1개월**. 시즌이 끝나면 티어 보상을 지급하고, 다음 시즌은 한 티어 아래에서 시작합니다.
- **매칭**: 티어 점수가 가까운 상대 + **클럽 전력(OVR) 차이 ±8 이내** 우선. 대기 시간이 길어지면 범위를 넓힙니다.
- **티어 구간 전력 보정**: 브론즈–실버 구간에서는 전력 차이를 일부 보정(능력치 상한 75)해서 신규 유저가 고과금 유저에게 일방적으로 지지 않게 합니다. 골드 이상은 보정이 없습니다.
