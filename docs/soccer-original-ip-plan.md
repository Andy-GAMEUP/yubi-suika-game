가제: **골목컵 (Alley Cup)** · 작성 2026-11-02
참고: [Pixel Cup Soccer 분석](pixel-cup-soccer-analysis.md). 장르와 일반적인 게임 방식만 참고합니다. 원작의 이름, 아트, UI, 데이터, 코드는 사용하지 않습니다.

## 1. 한 줄 컨셉
> 동네 골목팀을 이끌고 **매 경기 규칙이 바뀌는 엉뚱한 컵 대회**를 돌파하는, 3분짜리 한 손 픽셀 축구.

## 2. 원작과 확실히 다른 점

원작과 "같은 게임의 다른 이름"으로 보이지 않도록 핵심 축 세 가지를 바꿉니다.

| 구분 | 원작 (Pixel Cup Soccer) | 골목컵 |
|---|---|---|
| 세계관 | 국가대표·월드컵 풍 대회 | 가상 도시의 동네 클럽들 (옥상, 시장, 해변, 학교 운동장) |
| 경기 규모 | 11대11, PC·패드 중심 조작 | **5대5 풋살형**, 세로 화면, 한 손 조작 |
| 경기 시간 | 수 분 + 전후반 구성 | 1경기 3분, 연장 없이 바로 승부차기 |
| 혼돈 요소 | 경기장 장애물이 무작위로 등장 | 경기 전에 플레이어가 **룰 카드**를 고르고 상대도 카드를 낸다 |
| 장기 콘텐츠 | 커리어 모드 (구단 운영 + 상황 카드) | **로그라이트 컵 원정** + 동네 클럽 꾸미기 |
| 아트 | 정통 탑뷰 도트 | 2등신 캐릭터, 3/4 시점, 굵은 외곽선과 밝은 파스텔 색감 |

## 3. 타깃과 플랫폼
- **타깃:** 출퇴근·짬 시간에 하는 캐주얼·미드코어 남녀 15–35세. 축구 지식이 없어도 즐길 수 있어야 합니다.
- **플랫폼:** iOS·Android 우선 출시, 이후 Steam (패드 지원) 확장
- **화면:** 세로 모드 기본 (한 손 플레이)

## 4. 핵심 플레이

### 4.1 조작 (한 손)
| 입력 | 공 있을 때 | 공 없을 때 |
|---|---|---|
| 드래그 | 드리블 이동 | 이동 |
| 탭 | 가장 가까운 동료에게 패스 | 선수 전환 |
| 스와이프 | 슛 (길이 = 세기, 휘는 궤적 = 감아차기) | 슬라이딩 태클 |
| 길게 누르기 | 스프린트 | 압박 (상대에게 붙기) |
| 필살기 버튼 | 캐릭터 고유 기술 (게이지 충전 시) | — |

- 선수 전환은 자동이 기본이고, 숙련자는 수동으로 바꿀 수 있습니다.
- 보조 옵션: 자동 슛 조준, 자동 태클 타이밍

### 4.2 경기 규칙
- 5대5 (골키퍼 포함), 3분, 벽 반사 있음 (풋살장처럼 공이 담장에 튕김)
- 파울은 단순화: 과한 태클은 경고 아이콘 → 2회면 30초 퇴장
- 동점이면 바로 1:1 승부차기 (스와이프 슛 vs 탭 다이빙)

### 4.3 룰 카드 (이 게임만의 차별점)
경기 전 양 팀이 카드 1장씩을 내면, 그 경기에만 규칙이 바뀝니다.

| 카드 예시 | 효과 |
|---|---|
| 🌧 장마철 | 공이 미끄러지고 슬라이딩 거리 2배 |
| 🐔 탈출한 닭 | 닭이 경기장을 돌아다니며 공을 쪼아 방향을 바꿈 |
| 🎈 풍선 공 | 공이 가벼워 바람에 날림 |
| ⏱ 골든 골든 | 마지막 30초에 넣은 골은 2점 |
| 🧱 공사 중 | 경기장 가운데 벽이 생김 |
| 🍜 야식 배달 | 배달 오토바이가 주기적으로 가로질러 지나감 |

- 출시 시 30장, 시즌마다 10장씩 추가
- 카드끼리 조합되는 효과 (예: 장마철 + 풍선 공 = 물풍선)도 넣어 재미를 키웁니다.

### 4.4 캐릭터
- 선수마다 능력치 4개 (속도, 슛, 패스, 수비)와 **고유 기술 1개**
  - 예: "시장 아줌마" — 장바구니 휘두르기로 주변 상대를 밀어냄 / "태권 소년" — 돌려차기 슛
- 능력치는 상한선이 있고 레벨로만 성장합니다. 돈을 내면 강해지는 구조(페이투윈)는 만들지 않습니다.

## 5. 모드

| 모드 | 내용 | 출시 시점 |
|---|---|---|
| **컵 원정** (메인) | 5경기 연속 토너먼트. 경기 사이에 룰 카드·응원 아이템(1회성 강화)·선수 영입 중 하나를 선택하는 로그라이트 구조. 지면 원정 종료 | 출시 |
| 동네 리그 | 다른 유저 팀과 비동기 대전 (상대 팀은 AI가 조종). 주간 순위 | 출시 |
| 친선전 | 원하는 카드·경기장·팀으로 자유 대전, 같은 기기 2인 대전 | 출시 |
| 실시간 대전 | 1:1 (각자 5명 조작) 랭크전 | 출시 후 업데이트 |
| 미션 | 주간 챌린지 ("닭 카드로 3골 넣기" 등) | 출시 |

## 6. 메타 성장
- **동네 클럽:** 클럽하우스를 꾸밉니다 (트로피 진열장, 벽화, 유니폼 디자인, 엠블럼 에디터).
- **선수 수집:** 컵 원정에서 이긴 상대 선수를 영입할 수 있고, 중복 영입하면 레벨이 오릅니다.
- **카드 도감:** 룰 카드를 해금하고 경기마다 쓸 카드 덱 8장을 구성합니다.
- **시즌:** 8주 단위. 새 경기장, 카드, 선수 추가 + 시즌 패스

## 7. 수익 모델
- 무료 게임 + 다음 세 가지 수익원
  1. **꾸미기 판매:** 유니폼, 엠블럼, 클럽하우스 장식, 세리머니, 공 스킨
  2. **시즌 패스:** 무료 / 유료 단계 (약 9,900원)
  3. **보상형 광고:** 컵 원정에서 진 뒤 한 번 이어하기, 보상 2배
- 강제 광고(경기 사이 전면 광고)는 넣지 않습니다. "광고 제거 + 꾸미기 묶음" 상품 1종을 판매합니다.
- 능력치나 승패에 영향을 주는 상품은 팔지 않습니다.

## 8. 아트·사운드 방향
- 32×32 크기의 2등신 캐릭터, 3/4 시점 경기장, 굵은 외곽선과 파스텔 색
- 경기장마다 생활감 있는 배경: 시장 천막, 옥상 빨래, 운동장 철봉
- 사운드: 칩튠과 생활 소음(시장 호객, 매미 소리)을 섞은 BGM, 과장된 효과음
- 골 장면: 짧은 컷인과 화면 흔들림, 즉석 리플레이 3초

## 9. 기술 구조 (안)
| 영역 | 선택 | 이유 |
|---|---|---|
| 엔진 | Unity 6 LTS, 2D URP, Pixel Perfect Camera | 모바일·Steam 동시 대응, 팀 숙련도 |
| 시뮬레이션 | 고정 60틱 결정론적 물리 (자체 구현, 공 높이 z축 포함) | 리플레이·비동기 대전·실시간 대전에 같은 코드 사용 |
| AI | 유틸리티 AI + 포지션 슬롯 | 5대5에서 자연스러운 움직임, 난이도 조절이 쉬움 |
| 룰 카드 | 데이터로 정의하는 효과 시스템 (ScriptableObject + 효과 조합) | 시즌마다 카드를 코드 수정 없이 추가 |
| 백엔드 | Nakama 또는 PlayFab (계정, 리그, 클라우드 저장, 원격 설정) | 비동기 리그와 시즌 운영 |
| 실시간 대전 | 롤백 넷코드 (결정론적 시뮬레이션 활용) | 모바일 네트워크 지연에 강함 |
| 용량 | 첫 설치 150MB 이하, 시즌 리소스는 추가 다운로드 | 원작 617MB 대비 대폭 축소 |
| 보안 | 서버에서 경기 결과 재검증, Play Integrity·App Attest | 모드판·조작 방지 |

## 11. 리스크와 대응
| 리스크 | 대응 |
|---|---|
| 원작과 닮아 보인다는 지적 | 5대5·세로 화면·룰 카드·동네 세계관으로 차별화. 이름·도트 스타일은 법무 검토 후 확정 |
