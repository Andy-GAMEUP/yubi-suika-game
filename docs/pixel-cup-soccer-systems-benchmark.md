# Pixel Cup Soccer 시스템 벤치마크 — 조작·튜토리얼·설정·게임 모드

작성 2026-11-02 · 대상: Pixel Cup Soccer – Ultimate (`com.batovi.pcsue` v11, Mac에서 실행 중인 빌드)
관련: [원작 분석](pixel-cup-soccer-analysis.md) · [수치 분석](pixel-cup-soccer-tuning.md) · [골목컵 기획서](golmok-cup-gdd.md)

**근거와 표기**
- 근거 자료: 게임 내 한국어·영어 UI 문구(1,537개 키), 메뉴·힌트·컨트롤러 맵·대회·커리어 상황 카드 데이터, 클래스 1,120개의 메서드·필드 이름, 상수, 실행 중인 게임의 저장 파일(`localSave.xml`)
- **(관측)**: 데이터나 문구에서 직접 확인한 것. **(추정)**: 이름이나 구조에서 미루어 본 것
- 게임 문구는 요약해서 옮겼습니다.

## 1. 조작

### 1.1 입력 장치
| 항목 | 내용 |
|---|---|
| 지원 입력 | 터치, 키보드, 마우스, 게임패드(PlayStation·Xbox·Nintendo·MFi 등), Apple TV 리모트 (관측) |
| 논리 버튼 | 23개 (Button_1–16, 방향 4개, 일시정지·나가기·확인) |
| 액션 | 이동, 패스, 킥, 스킬, 보조 스킬(커브), 골키퍼, 선수 변경, 전술 ↑↓, 태도 ←→, 일시정지 |

### 1.2 두 가지 컨트롤 스타일
| | **PCS (간단)** | **표준 (Traditional)** |
|---|---|---|
| 개념 | 버튼 수를 줄이고 **누르는 시간과 공 소유 여부**로 의미를 나눔 | 기능마다 전용 버튼 |
| 패스 | 버튼 하나: 짧게 = 짧은 패스, 조금 길게 = 스루패스, 길게 = 로빙 | 짧은 패스·스루패스·로빙 버튼이 각각 있음 |
| 선수 변경 | 공이 없을 때 패스 버튼 | 전용 버튼 |
| 대상 | 캐주얼, 모바일(터치는 사실상 PCS만) | 보통·하드코어, 패드 |

### 1.3 모바일 터치 레이아웃
- **가상 스틱 1개 + 버튼 2개(패스, 슛) + 상황에 따라 나타나는 스킬 버튼 1개** (관측: 아이콘 6종, 버튼 필드)
- **공수 전환 시 버튼이 바뀝니다**: 공을 잃으면 패스 → 선수 변경, 슛 → 태클로 아이콘과 라벨이 바뀝니다. 페널티 방어 때는 별도 배치를 씁니다.
- 커브: 모바일은 보조 버튼 없이, 슛·패스 직후 방향을 입력하면 휩니다.

### 1.4 상황별 입력
| 상황 | 입력 → 결과 |
|---|---|
| 패스 | 누른 시간: 약 0.2초 미만 짧은 패스 → 스루패스 → 0.4–0.9초 로빙. 1.1초를 넘기면 헛발질하고 넘어짐 |
| 슛 | 누른 시간으로 종류·힘·정확도 결정, 충전 중 방향으로 조준. 1초를 넘기면 오차 급증(공이 빨갛게 표시) |
| 페이크 슛 | 슛 충전 중 패스 버튼 (특성 필요) |
| 백힐 패스 | 뒤로 빠르게 조준 (특성 필요) |
| 수비 | 슛 버튼 = 슬라이딩 태클, 패스 버튼 = 선수 변경 |
| 골키퍼 (수동·PK) | 방향 이동, 슛 버튼 = 낮은 점프, GK 버튼 = 높은 점프. GK 버튼은 전진 돌진에도 씀 |
| PK 키커 | 아무 버튼이나 누르면 자동 도움닫기. 공에 가까울 때 찰수록 정확. 슛 버튼은 강하지만 부정확(오차 6°), 패스 버튼은 느리지만 정확(3°) |
| 경기 중 전술 | 방향 버튼으로 전술(보통·압박·역습·커버) ↑↓, 태도(수비·보통·공격) ←→ 순환 |

### 1.5 스킬 발동: 머리 위 "별" 색깔
| 별 색 | 발동 가능한 행동 |
|---|---|
| 흰색 | 스프린트 (스킬 버튼, 쿨다운 약 10초) |
| 노란색 | 드리블 회피, 블록·정면 태클, 점프 회피, 칩킥, 다이빙 헤더, 오버헤드, 시저킥, 하프발리, 슈퍼 세이브 |
| 빨간색 | 슈퍼슛 (팀 쿨다운 50초, 맞은 상대 5–10초 기절) |
| 없음(자동) | 볼 컨트롤, 가슴 트래핑, 헤더 등 패시브 특성 |

→ **스킬 버튼 하나로 수십 가지 기술을 처리**합니다. 지금 쓸 수 있는 행동은 별 색으로 알려 줍니다.

### 1.6 선수 변경 규칙 (4종)
| 모드 | 기준 |
|---|---|
| 공에 가장 가까운 선수 (보조) | 거리 |
| 자기 골문 쪽에서 공에 가까운 선수 | 수비 위치 고려 |
| 조준한 방향의 선수 (보조 없음) | 스틱 방향 |
| 클래식 (기본값) | 수비 위치에서 가장 가까운 선수 |

### 1.7 보조(어시스트) 옵션 — 컨트롤러별로 따로 저장
| 옵션 | 효과 | 현재 저장값 |
|---|---|---|
| 슛 보조 | 슛 방향을 골대 쪽으로 자동 보정 | 켬 |
| 패스 보조 | 패스 대상 찾기와 정확도 보정 | 켬 |
| 자동 행동 | 헤더·오버헤드 등을 자동 실행 | 켬 |
| 공 쪽으로 방향 조정 | 공이 가까우면 자동으로 공을 바라봄 | 켬 |
| 자동 선수 변경 | 더 나은 선수로 자동 전환 | 켬 |
| 수동 골키퍼 | 슛이 올 때 GK를 직접 조종 | 끔 |

- 보조 설정은 입력 데이터에 실려 전송됩니다. 그래서 같은 경기 안에서도 플레이어마다 다른 보조를 쓸 수 있습니다(온라인 포함, 추정).

### 1.8 키 설정과 로컬 멀티
- 키보드 프로필 3개, 패드 프로필 2개, 표준 스타일 전용 프로필이 있습니다. 키를 다시 배정하면 겹치는 키는 서로 바뀌고, 10초 안에 확인하지 않으면 원래대로 돌아갑니다.
- 컨트롤러 배정 화면에서 컨트롤러 아이콘을 홈(왼쪽)·중립·원정(오른쪽)으로 옮깁니다. **팀당 최대 4명 협동**, 파티 모드는 최대 8명입니다.

## 2. 튜토리얼·온보딩

### 2.1 첫 실행 흐름 (관측, 실제 저장 기록으로 확인)
1. **"당신은 어떤 종류의 축구 선수입니까?"**: 프로필 4종 중 하나를 고르면 조작 스타일·보조·난이도가 한 번에 정해집니다.

   | 프로필 | PC | 모바일 |
   |---|---|---|
   | 캐주얼 | PCS, 보조 전부, 쉬움 | 보조 전부, 쉬움 |
   | 보통 | 표준, 일부 보조, 보통 | 일부 보조, 보통 |
   | 하드코어 | 표준, 보조 없음, 어려움 | 일부 보조, 어려움 |
   | 커스텀 | 직접 조정 | 직접 조정 |

2. **메인 메뉴 환영 힌트 3개**: 첫 번째는 환영, 두 번째는 게임 방법이나 친선 경기로 유도, 세 번째는 힌트를 끄는 방법 안내입니다. 실제로 4초 동안 연속으로 노출됐습니다.
3. **친선 경기 버튼 강조** → 첫 경기 → 첫 승리
4. 나머지 환영 힌트(협동, 파티, 커리어 등)는 다음 방문 때로 미룹니다. 방문 횟수별로 묶어서 보여 줍니다(추정).

### 2.2 액션 튜토리얼 (경기 안의 짧은 힌트)
| 항목 | 가르치는 것 |
|---|---|
| 이동 | 방향 입력 |
| 패스 | 길게 누를수록 긴 패스 |
| 슛 | 누른 시간으로 종류·힘·정확도 결정 |
| 태클 | 공이 없을 때 슛 버튼 |
| PK 도움닫기 / 킥 / 방어 | 자동 도움닫기, 가까울 때 차기, 낮은·높은 점프 |
| 체력 | 공을 몰고 달리면 번개 표시와 함께 느려짐 |
| 휴식 | 패스하거나 멈춰서 회복 |
| 스킬 / 슈퍼슛 | 별이 뜨면 스킬 버튼, 빨간 별이면 슈퍼슛 |

- 힌트는 최소 3초 동안 보이고, 2.5초 전에는 넘길 수 없습니다. 해당 버튼을 강조 표시합니다.
- 튜토리얼 경기와 PK 튜토리얼은 **도움말 메뉴에서 직접 들어가는 선택형**입니다. 첫 경기에 강제로 넣지 않습니다(저장 기록 기준 추정). 다 마치면 업적("게임 준비!")을 줍니다.

### 2.3 연습(드릴) 모드
- 코드에는 목표 횟수와 실패 횟수가 정해진 드릴 미니게임이 15종 넘게 있습니다. 예: 짧은 패스 10회, 로빙 5회, 슛 5골/5실패, 태클 성공 5/실패 10, 스프린트, 오버헤드, GK 선방, 프리킥, 다이빙 헤더, 장애물 점프.
- 하지만 **출시판 메뉴에는 "페널티 매치" 하나만** 노출됩니다. 드릴 대사는 현지화되지 않아서 숨겨진 미완성 기능으로 보입니다(추정).

### 2.4 도움말 화면
| 메뉴 | 내용 |
|---|---|
| 컨트롤 | 동작마다 그림과 설명. 조작 스타일에 따라 설명문이 바뀜 |
| 스킬 가이드 | 45종 이름·설명·XP 비용·포지션 제한 |
| 능력치 안내 | 8종 능력치 설명 |
| 용어집 | 킥 7종, 패스 7종, 포지션, 경기 유형 |
| 바로가기 | 튜토리얼 경기, PK 튜토리얼, 연습 |

### 2.5 코치 캐릭터 힌트 시스템
- 힌트는 데이터 파일로 정의합니다. 속성은 문구, 캐릭터, 가리킬 버튼, 버튼을 눌러야 넘어가는지, 반복 여부, 자동 닫힘 시간입니다.
- 힌트마다 마지막으로 보여 준 시각을 저장해서 같은 힌트를 반복하지 않습니다.
- 묶음 구성: 메인 메뉴 7, 친선 3, 토너먼트 3, 커리어 약 40, 파티 약 8, 경기장 상황 27종(잔디 상태, 동물, 침수 등), 업데이트 공지
- 전체 힌트를 끄는 옵션이 있고, 커리어 힌트는 따로 끌 수 있습니다.

### 2.6 리뷰 요청
- 먼저 "게임이 마음에 드나요?"를 묻습니다. **예**라고 답한 유저만 스토어 리뷰로 보내고, **아니오**라고 답한 유저에게는 피드백 메일을 안내합니다. 응답은 한 번만 받습니다.
- 첫 승리 직후에는 묻지 않았습니다. 몇 경기나 세션 뒤에 묻는 것으로 보입니다(추정).

| 옵션 | 선택지 | 현재 저장값 |
|---|---|---|

### 3.3 기타
- **오디오**: 음악과 효과음을 각각 켜고 끄며 볼륨 단계를 조절합니다. **언어**: 약 40개(한국어 포함).
- **커리어**: 힌트, 이사회 음성, XP 자동 배분, 팀 스킬 초기화, 시즌 포기, 클럽 삭제, 상황 이벤트 끄기
- **데이터**: 팀 DB 초기화, 리그 팀 초기화, 업데이트할 팀 선택, 전체 초기화, 팀 파일 내보내기·가져오기
- **클라우드**: iCloud·Steam Cloud 동기화. 더 최신 저장이 발견되면 충돌 안내를 띄웁니다.

## 4. 메인 메뉴와 게임 모드

### 4.1 메인 메뉴 구성
| 메뉴 | 내용 |
|---|---|
| 친선 경기 | CPU 또는 친구와 빠른 경기, 승부차기 경기 |
| 추천 경기 | 서버에서 내려주는 기간 한정 특별 경기 (없으면 "곧 열림" 안내) |
| 토너먼트 | 공식 컵·리그 |
| 파티 토너먼트 | 친구들과 하는 커스텀 대회 |
| 온라인 (일반 / 랭크) | 랭크는 "곧 출시" 상태 |
| 커리어 | 클럽 경영 모드 |
| 모드·작업장 | 팀·대회 편집기, Steam 워크숍 |
| 게임 방법 | 튜토리얼, PK 튜토리얼, 연습, 스킬 가이드 |
| 설정, 명예의 전당, 크레딧, 문의, 종료 | |

## 5. 커리어(경력) 모드

### 5.1 진입과 온보딩
- **해금**: 친선이나 토너먼트에서 1승. 들어가기 전에 다른 모드를 먼저 해 보라고 권합니다 → 조작을 익힌 뒤 들어오는 2차 모드입니다.
- **코미디 인트로 컷신 (7단계)**: 초라한 교외 클럽 → 이사회가 "못 이기면 시장에게 쫓겨난다"며 걱정 → 섬에 있는 유명 코치를 "클럽 100% 지배권"이라는 말로 속여 데려옴 → 코치 도착 → 선수단 버스 도착(초라한 현실) → 이사회 설명 → 클럽 전경. 길게 눌러 건너뛸 수 있습니다.
- **클럽 생성**: 팀명, 경기장명, 깃발(무작위 생성), 유니폼, 선수 외형, 코치 외형, 주장. 나중에 해도 된다고 안내하고, 상황 카드 켜기·끄기도 고릅니다.
- **저장**: 슬롯 4개, 클라우드, 시즌별 파일. 라인업 프리셋은 A·B·C 3개입니다.

## 6. 골목컵에 적용할 점

[골목컵 기획서](golmok-cup-gdd.md)(무료 플레이, 카드 RPG, 온라인 티어전)를 기준으로 정리했습니다.

### 6.1 조작
| 원작 요소 | 골목컵 적용 |
|---|---|
| PCS 2버튼(누르는 시간 = 의미) + 상황형 스킬 버튼 1개 | **모바일 기본 조작으로 채택**. 스틱 + 패스 + 슛 + 스킬. 표준(버튼 분리) 방식은 패드·PC 옵션 |
| 공수 전환 시 버튼 아이콘·라벨 변경 | 그대로 적용 (패스 ↔ 선수 변경, 슛 ↔ 태클) |
| 머리 위 별 색으로 쓸 수 있는 스킬 표시 | 적용. 카드 **특성**이 별 색 행동을 연다 → 카드 가치가 눈에 보임 |
| 보조 6종 + 선수 변경 모드 4종, 컨트롤러별 저장 | 적용. **랭크전에서는 보조 허용 범위를 제한하거나 보조 사용을 표시**할지 결정 필요 (공정성) |
| PK: 슛 버튼 강하지만 부정확, 패스 버튼 정확하지만 약함 | 적용 (위험·보상 선택) |

### 6.2 온보딩
| 원작 요소 | 골목컵 적용 |
|---|---|
| 첫 실행 성향 4택 → 조작·보조·난이도 일괄 설정 | 적용 (3택으로 단순화) |
| 경기 안 3초 액션 힌트, 튜토리얼은 선택형 | **첫 경기를 짧은 강제 튜토리얼 경기로** 바꿈 (무료 게임은 첫 5분 이탈이 큼) |
| 결핍 경험 → 스킬 구매 유도 | **첫 뽑기·첫 강화 유도에 응용**: 첫 경기에서 약한 슛을 겪게 한 뒤 → 무료 고급 덱 → 강화 |
| 숨겨진 드릴 모드 | 출시 범위에 **드릴 5종**(패스, 슛, 태클, GK, 스킬)을 넣고 일일 미션과 연결 |
| 코치 캐릭터 힌트를 데이터로 정의 | 적용. 라이브 공지·이벤트 안내에 재사용 |
| "마음에 드나요?"를 먼저 묻고 리뷰 요청 | 적용 (첫 승격·첫 레전드 획득 같은 좋은 순간에) |

### 6.3 설정
- 경기 시간: 온라인 랭크는 3분 고정, 친선·시즌 리그는 1–10분 선택
- 경기 속도·파울·오프사이드·슈퍼슛 토글은 **친선 전용**, 랭크는 고정 규칙
- 모바일 기본값: 줌 넓게, UI 속도 빠르게, 그림자·관중 끄기 옵션(저사양)

### 6.4 모드
| 원작 요소 | 골목컵 적용 |
|---|---|
| 대회 형식 데이터 정의(리그, 녹아웃, 3–12조, 3위 진출 표) | **월간 티어 토너먼트와 시즌 리그(PvE) 엔진으로 그대로 활용**. 서버에서 내려주는 대회 데이터 하나로 운영 |
| 해금 사슬 + 기간 한정 임시 해금 | PvE 대회 해금 사슬과 이벤트로 재방문 유도 |
| 난이도 리본 | PvE 대회 ★1–★3 클리어 보상 (뽑기 재화 지급처) |
| 추천 경기(서버 이벤트 경기) | **주간 이벤트 매치**: 실제 축구 일정에 맞춘 대진, 이벤트 트로피, 한정 카드 조각 |
| 온라인 이탈·동기화 실패 처리 | 기획서 9.4절 티켓 환불 규칙과 연결 |
| 6리그 26단계, 하위 큰 획득 점수 / 상위 작은 점수 | 기획서 9.5절 7티어 설계와 비교해 **하위 구간 빠른 승급** 원칙 반영 |
| 파티 특수 규칙(정한 골 수 선취 승, 특별 골) | **카오스 컵·친구 대전 규칙**으로 채택 |
| 업적 절반이 골 기술 | 일일·주간 미션과 시즌 패스 과제로 전환 (기술 학습 유도) |
| 원작에도 미출시 카드 팩 경제 흔적 | 원작이 가려다 멈춘 방향 → 골목컵의 차별화 지점이자 **검증되지 않은 리스크** |

### 6.5 커리어 → 카드 RPG 클럽 모드
| 원작 요소 | 골목컵 적용 |
|---|---|
| 8팀 홈·원정 리그, D → A 승강, 디비전별 경기장·관중 성장 | **시즌 리그(PvE)** 기본 구조로 채택. 디비전 보상 상자 |
| 30인 스쿼드 + 에너지(경기당 −20%) → 로테이션 강제 | **2군 카드의 가치**를 만드는 장치로 채택. 단, 회복 아이템을 유료로 팔면 피로 설계가 과금 압박으로 느껴지므로 주의 |
| XP로 스킬 구매, 별 등급 잠금 | 카드 강화(+3·+6·+9 특성 슬롯)와 특성 훈련으로 이미 반영 (기획서 5.4절) |
| 선수 유형 18종 템플릿 | 카드 생성 템플릿으로 참고 (수치는 자체 설계) |
| **이사회 상황 카드 덱** | **"구단 이벤트" 시스템으로 채택**. 내 보유 카드가 이야기 주인공이 되고, 효과는 사기·컨디션·임시 버프·재화·홈구장 상태로 연결. 텍스트와 상태 값만으로 이벤트를 수백 개 만들 수 있는 저비용 콘텐츠 |
| 돈 = 있음·없음 두 상태, 돈이 없어도 이야기가 진행 | 이벤트 선택에 클럽 코인 비용을 붙이되 **무료 우회 선택지를 반드시 남김** |
| 경영 결정 → 다음 경기 경기장 변화 | **PvE에서만** 적용 (PvP는 공정성 때문에 끔) |
| 해고 없음, 강등까지만 | 적용. 대신 원작에 없는 **시즌 이사회 미션 + 달성 보상**을 추가 |
| 코미디 인트로(속아서 부임한 감독) | 세계관 톤 참고. 우리 이야기는 동네 클럽 설정으로 새로 씀 |

## 7. 한계
- 출시판에서 숨겨진 기능(드릴, 랭크전, 카드 팩 상점)은 데이터상으로만 확인했습니다. 실제 동작은 알 수 없습니다.
- 커리어 XP·능력치 성장 공식은 상수와 저장 데이터로 추정했습니다(해당 함수는 디컴파일하지 않음).
- 메인 메뉴 버튼 순서는 코드 선언 순서 기준이라 실제 화면과 다를 수 있습니다.
